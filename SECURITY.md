# Seguridad

## Alcance

Este repositorio contiene la edición pública de una aplicación local de gestión de informes. No incluye datos ni configuración de la instalación laboral. La publicación del código no implica que el servidor esté preparado para exponerse a internet.

## Reportar un problema

Si GitHub ofrece la opción **Security → Report a vulnerability** en este repositorio, utiliza ese canal privado. Si no está disponible, solicita al mantenedor un canal privado de contacto sin describir el fallo en público.

Incluye los pasos de reproducción con datos ficticios, el comportamiento esperado y el resultado observado. Nunca adjuntes bases reales, contraseñas, cookies, nombres de trabajadores ni documentos de incidentes. No publiques detalles de explotación en una incidencia pública.

## Datos publicados por accidente

Retira el acceso a los datos, rota las credenciales afectadas y revisa el historial Git. Borrar un archivo en un commit nuevo o agregarlo a `.gitignore` no lo elimina de commits anteriores. La eliminación del repositorio tampoco retira copias que terceros ya hayan descargado.
